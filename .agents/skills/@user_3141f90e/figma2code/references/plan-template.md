# PLAN.md 模板

`PLAN.md` 是阶段 1 的产物。把这份模板复制到用户项目里、填好、给用户确认后再进入下一阶段。

## 模板结构

```markdown
# 页面还原计划 — <页面名>

## 概览
- **来源**：<Figma/Mastergo URL 或 file + node id>
- **顶层节点 id**：<id>
- **设计稿基准宽度**：<375 / 750 / 1440>
- **目标视口**：<例如 375 / 768 / 1440>
- **目标框架与版本**：<例如 React 19 + Vite / Vue 3 + Composition API / 微信小程序原生 / uni-app / 等>
- **TS / JS**：<TypeScript / JavaScript>
- **样式方案**：<Tailwind / CSS Modules / SCSS / styled-components / WXSS / 等>
- **是否嵌入已有项目**：<新项目 / 嵌入到 xxx 项目>
- **现有组件库**：<Element Plus / Vant / Ant Design / shadcn/ui / 内部库 xxx / 无>
- **现有 token 系统**：<已有，命名规范如 `--color-primary` / 已有 SCSS 变量 `$brand-primary` / 无>
- **产物去处**：<项目路径 / artifact / 小程序工程>
- **响应式范围**：<单视口 / 多视口 / 流式>
- **交互态范围**：<是 / 否 / 部分>（hover、active、disabled、loading）

## 复用现有的部分（如阶段 1 第 1 步确认了现有组件库）
列出哪些设计稿元素直接对应现有组件，不重新造：
| 设计稿元素 | 现有组件 | 处理方式 |
| --- | --- | --- |
| 主按钮 | `<el-button type="primary">` | 直接用 |
| 标签 Tag | `<el-tag>` | 包一层 `<BrandTag>` 改样式 |
| 卡片 | （现有库没有） | 自建 `<DoctorCard>` |

| `--color-text-muted` | #... | 次要 / 提示文本 |
| `--color-border` | #... | 分隔线、轮廓 |
| ... | ... | ... |

| `--text-display` | ... | 32 / 40 | 600 | Hero 大标题 |
| `--text-h1` | ... | 24 / 32 | 600 | 区块标题 |
| `--text-body` | ... | 14 / 22 | 400 | 正文 |
| `--text-label` | ... | 12 / 16 | 500 | 标签 / 辅助 |
| ... | ... | ... | ... | ... |

### 间距
4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 — 任何不在标准尺度上的特殊值要单独标注。

### 圆角
4 / 8 / 12 / 16 — 按设计稿里实际用到的来记，不要凭空补全尺度。

### 阴影（如果有）
- Shadow-sm: `0 1px 2px rgba(0,0,0,.04)`
- ...
```

## 几条经验

- **不要发明设计稿里没有的 token**。如果某条边框用了一个游离色，就在那个模块的备注里单独标注，不要为它新增一个 token。
- **间距尺度是观察出来的，不是规定的**。设计稿里只用了 8/16/24，那你的尺度就是 8/16/24，不要"先准备一些可能用到的"。
- **如果文件里已经定义了 Figma Variables / Mastergo styles，优先用它们的命名**——用户代码里很可能已经按这个命名了。
