### 4.1 表结构设计

#### 4.1.1 表名：`table_name`

**表说明**：[表的用途说明]

**建表语句**：
```sql
CREATE TABLE `table_name` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `field1` varchar(100) NOT NULL COMMENT '字段1说明',
  `field2` int(11) DEFAULT '0' COMMENT '字段2说明',
  `field3` json DEFAULT NULL COMMENT 'JSON字段说明',
  `status` tinyint(4) NOT NULL DEFAULT '1' COMMENT '状态：1-有效 0-无效',
  `created_by` bigint(20) NOT NULL COMMENT '创建人ID',
  `created_at` timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_by` bigint(20) DEFAULT NULL COMMENT '更新人ID',
  `updated_at` timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted` tinyint(1) DEFAULT '0' COMMENT '逻辑删除：0-未删除 1-已删除',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_field1` (`field1`) COMMENT '唯一索引',
  KEY `idx_status` (`status`) COMMENT '状态索引',
  KEY `idx_created_at` (`created_at`) COMMENT '创建时间索引'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='表注释';
```

**字段说明**：
| 字段名 | 类型 | 是否必填 | 默认值 | 说明 | 示例值 |

| id | bigint(20) | 是 | AUTO | 主键ID | 1 |
| field1 | varchar(100) | 是 | - | 字段1说明 | "value" |
| field2 | int(11) | 否 | 0 | 字段2说明 | 100 |
| status | tinyint(4) | 是 | 1 | 状态枚举 | 1 |

### 4.3 数据迁移方案

#### 新增表迁移
```sql

-- 初始化数据（如需要）

```

#### 数据变更迁移
```sql
-- 备份原表
CREATE TABLE `table_name_backup_20240101` LIKE `table_name`;
INSERT INTO `table_name_backup_20240101` SELECT * FROM `table_name`;

-- 添加新字段
ALTER TABLE `table_name` ADD COLUMN `new_field` varchar(100) COMMENT '新字段';

-- 数据迁移
UPDATE `table_name` SET `new_field` = 'default_value' WHERE `new_field` IS NULL;
```

#### 回滚方案
```sql
-- 回滚表结构变更
ALTER TABLE `table_name` DROP COLUMN `new_field`;

-- 恢复数据
TRUNCATE TABLE `table_name`;
INSERT INTO `table_name` SELECT * FROM `table_name_backup_20240101`;
```
