# 前端 UI 工程 — 模板与清单

> 本文件为 `frontend-ui-engineering` 的配套模板。所有 `<X>` 为占位。

## 一、反 AI 审美对照表（全部避免）

| AI 默认 | 问题 | 生产级做法 |
|---|---|---|
| 紫/靛蓝铺满 | 看起来都一样 | 用项目真实调色板 |
| 过度渐变 | 视觉噪声 | 扁平或轻微渐变 |
| 圆角拉满 | 忽略层级 | 用设计系统一致圆角 |
| 模板 hero | 与内容无关 | 内容优先布局 |
| Lorem 占位 | 掩盖真实排版问题 | 真实占位文案 |
| 到处超大 padding | 破坏层级 | 一致间距刻度 |
| 划一卡片网格 | 忽略信息优先级 | 目的驱动布局 |
| 层层阴影 | 干扰内容/拖慢低端机 | 细微或无阴影 |

## 二、状态管理选型

| 方式 | 适用 |
|---|---|
| useState | 组件内 UI 状态 |
| 提升状态 | 2-3 兄弟组件共享 |
| Context | 主题/鉴权/语言（读多写少） |
| URL 状态 | 过滤/分页/可分享 |
| Server 状态(RQ/SWR) | 带缓存远程数据 |
| 全局 store | 全应用复杂客户端状态 |

> prop drilling 超 3 层 → 用 Context 或重组。

## 三、可访问性清单（WCAG 2.1 AA）

- [ ] 所有交互元素可键盘访问（Tab 走一遍）
- [ ] 无可见文字元素有 `aria-label`
- [ ] 表单 input 有 `<label>` 或 `aria-label`
- [ ] 对话框打开移动焦点并陷阱聚焦
- [ ] 空态/错误态/加载态都处理（非空屏）
- [ ] 不只靠颜色传信息（配图标/文字）
- [ ] 对比度：正文 4.5:1，大字 3:1
- [ ] 不跳标题层级

## 四、间距与排版

- 间距走刻度（如 0.25rem 增量）：`p-4`(16px) / `gap-3`(12px)；不发明 13px/2.3rem。
- 层级：h1 页标题 → h2 段 → h3 子段 → body → small；不跳级。

## 五、组件文件结构（同目录聚合）

```
src/components/TaskList/
  TaskList.tsx        实现
  TaskList.test.tsx   测试
  TaskList.stories.tsx 故事(如用)
  use-task-list.ts     自定义 hook(复杂状态)
  types.ts             组件类型
```

## 六、响应式断点

测：320px / 768px / 1024px / 1440px（移动优先）。

## 七、构建后自检

- [ ] 组件无控制台错误
- [ ] 交互元素可键盘访问
- [ ] 屏幕阅读器可传达结构内容
- [ ] 响应式四断点可用
- [ ] 加载/错误/空态齐备
- [ ] 遵循设计系统（间距/颜色/排版）
- [ ] 无 axe-core 可访问性告警
